# ResolveX

ResolveX is a complaint management and escalation system developed using JSP and PostgreSQL.

## Project Overview
The project was designed to help users raise, track, and manage complaints efficiently through a structured escalation system. It includes complaint registration, status tracking, admin management, and department allocation features.

## Technologies Used
- JSP (Java Server Pages)
- Java
- PostgreSQL
- PGAdmin 4
- Eclipse IDE
- HTML/CSS

## Features
- User complaint registration
- Complaint tracking system
- Admin login and dashboard
- Complaint status updates
- Department-based complaint management
- Slot assignment functionality
- Forgot password and logout modules

## JSP Modules
- index.jsp
- adminLogin.jsp
- adminDashboard.jsp
- dashboard.jsp
- raiseComplaint.jsp
- trackComplaint.jsp
- updateStatus.jsp
- deleteComplaint.jsp
- forgotPassword.jsp
- logout.jsp

## Database
The project uses PostgreSQL with tables for:
- Complaints
- Admins
- Departments

SQL scripts are included inside the database folder.
